# Scriptable iPhone Widgets

Large Scriptable widgets for Booking Manager daily guest status.

- `iphone-bookings-widget-today.js` shows today's check-ins, check-outs, and occupied rooms.
- `iphone-bookings-widget-tomorrow.js` shows tomorrow's check-ins, check-outs, and occupied rooms.

Before pasting into Scriptable, replace:

- `YOUR_WIDGET_TOKEN`
- `YOUR_VERCEL_PROTECTION_BYPASS_TOKEN`

The real tokens are intentionally not committed because this GitHub repository is public.
